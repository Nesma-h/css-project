A modern and responsive gaming-themed website built as a Front-End project using **HTML5** and **CSS3**.

The project presents a complete gaming platform interface with multiple sections for games, players, tournaments, products, team members, and live content.

## ✨ Features

- 🎮 Modern gaming-themed user interface
- 📱 Responsive layout for different screen sizes
- 🕹️ Gaming and NFT-focused sections
- 🏆 Games and tournaments showcase
- 👥 Players and team members sections
- 🛍️ Products showcase
- 📺 Live/broadcast section
- 🎨 Clean and visually engaging design
- 🧩 Well-structured HTML and CSS

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Responsive Web Design**
